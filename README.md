# 🗄️ Smart Drawer System (Raspberry Pi)

An automated Smart Drawer management system powered by Raspberry Pi, designed to streamline storage tracking, access control, and inventory monitoring.

---

## 📌 Project & Academic Disclaimer

> **Important Note on Project Status:**  
> This project was developed as an academic **Final Project (*Tugas Akhir*)**. Due to academic timelines and submission deadlines, active development was officially concluded to meet graduation and grading requirements. The project has been formally evaluated and graded.
> 
> As a result, the current codebase still contains **known bugs, edge cases, and areas with significant room for optimization/refactoring**. It serves primarily as a functional proof-of-concept and academic submission.
